# Стиль-гайд: пиксель-арт WW2 Air Battles

Источник истины по палитре и читаемости — `GDD.md`, раздел Art direction. Этот файл фиксирует, как именно генерировать и принимать арт.

## Базовые параметры

| Параметр | Значение |
| --- | --- |
| Сетка | 1×: арт-пиксель = экранный пиксель (smoke-тест NB2.1; 2× через Pixel Engine отклонён) |
| Самолёты | исходник 64×64, показ 64 px, nearest, целый масштаб |
| Боссы | исходник 160×96–192×128 |
| Фон | слой 540×960, вертикальный wrap 960+240 |
| Иконки HUD | 24×24, 1:1, без масштабирования |
| Вид | сверху, нос вверх, лёгкий наклон отсутствует |
| Свет | верхне-левый, без резких теней |
| Контур | 1 px, кремовый `#D9D2C3` у игрока, тёмно-серый у врагов |

## Палитра

`#8FA6B2` небо · `#3B4A57` глубина · `#D9D2C3` облака/контур · `#4A5D3A` игрок · `#6B7F5A` блик игрока · `#4F4F4F` враги · `#FFD166` вражеские пули · `#B23A2E` опасность/элита/HP · `#F2EDE2` трассеры.

Красный — только опасность и элита. Жёлтый — только вражеские снаряды. Белый — только снаряды игрока.

## Читаемость

- Игрок всегда оливковый с кремовым контуром, враги — серые, элита — серый + красный акцент.
- Силуэт узнаётся на 48 px: Ла-5/Як-3 — одномоторный, Аэрокобра — длинный нос, Ju 87 — «лапти» шасси, Bf 110/Ju 88 — два мотора, Fw 200 — четыре.
- Фон приглушённый: небо и земля не ярче 60% насыщенности пуль.
- Никакой нацистской символики; опознавательные знаки нейтральные (звёзды/полосы).

## Референс и пресет

- Первый утверждённый спрайт игрока становится style reference (`style_asset_ids`) для всех последующих.
- Утверждённые `asset_id` записывать сюда:

## Иконки перков (`ui_perk_*`)

- **Размер:** файл 24×24 px, показ 1:1 в плашке слота 26×26 (зазор 1 px даёт сама плашка). Арт-пиксель = экранный пиксель.
- **Стиль:** плоские chunky-силуэты, 1 px контур, верхне-левый свет, без сцены и без текста; узнаваемость проверена на 24 px и в 6× зуме.
- **Палитра:** GDD-палитра; основа — металл `#8FA6B2`/`#869FA6`, глубина `#3B4A57`, кремовый `#D9D2C3`/`#E5DDC6`, олива `#4A5D3A`/`#505F40` (тяжёлый калибр), контур `#0F1B27`. Красный `#B23A2E` в иконках не используется — он остаётся за опасностью и элитой.
- **Состав листа (2026-10-28):** спарка (два ствола с вспышками), бронебойная пуля, две ракеты, осколочный взрыв, прицел-сетка, тяжёлый снаряд, гаечный ключ, снежинка + щит (хладнокровие), кольцевая ударная волна (аварийный сброс).
- **Ограничение 24 px:** 1–3 крупные формы на иконку. Двухэлементные сюжеты (щит + снежинка) на 24 px сливаются — на будущее просить одну форму с акцентом внутри.
- **Контраст на HUD:** тёмный контур `#0F1B27` читается на средней плашке; если плашка слота станет темнее `#3B4A57`, тёмные иконки (прицел) требуют светлой подложки или кремовой обводки.
- **Интеграция:** `assets/art/ui_perk_*.png`, импорт per-texture `compress/mode=0`, mipmaps off, `texture_filter` nearest; логика HUD (`LevelController.hud.set_perks`) не меняется — меняется только отрисовка слота.
