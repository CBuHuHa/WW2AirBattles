# assets/audio — плейсхолдерные звуки M3-D

## Происхождение

Все WAV в этом каталоге **сгенерированы процедурно** скриптом
`tools/generate_audio.py` (Python 3, только stdlib: `wave`, `struct`, `math`, `random`, `array`).
Внешние сэмплы, библиотеки и сеть не используются — это **generated placeholder, no external samples**.
Так закрывается GDD «Assets» для ключей `music_loop`, `sfx_combat`, `sfx_bomb`, `sfx_ui`
(Source = `placeholder`).

## Формат

| Параметр | Значение |
| --- | --- |
| Каналы | mono |
| Частота | 22050 Hz |
| Глубина | 16-bit PCM (WAV, little-endian) |
| Пик | −3.0 dBFS, без клиппинга |
| Seed | `20261027` (детерминированно: повторный запуск даёт те же файлы) |

| Файл | Длительность | Назначение | SFX-ключ AudioManager |
| --- | --- | --- | --- |
| `music_loop.wav` | 64.000 с | 32 такта @ 120 BPM, 4/4, A minor: дрон A1/E2, остинато виолончели, литавры, малый барабан, мотив валторны, тихая подложка | `music` (loop) |
| `player_shot.wav` | 0.060 с | автострельба Ла-5: сухой щелчок + шум | `player_shot` |
| `enemy_hit.wav` | 0.050 с | попадание по врагу/боссу: металлический тик | `enemy_hit` |
| `player_hit.wav` | 0.200 с | попадание по игроку: низкий удар + шум | `player_hit` |
| `enemy_explosion.wav` | 0.420 с | взрыв обычного врага и бомбы босса | `enemy_explosion` |
| `bomb.wav` | 1.000 с | бомба игрока: большой низкий взрыв | `bomb` |
| `pickup.wav` | 0.230 с | подбор ремкомплекта: восходящий чистый сигнал | `pickup` |
| `boss_alarm.wav` | 1.100 с | тревога босса и смена фазы: два тона | `boss_alarm` |
| `ui_click.wav` | 0.040 с | клик UI (пауза, бомба, «В бой») | `ui_click` |

Суммарный размер всех WAV — около 2.82 MiB (≤ 4 MiB по бюджету M3-D).

Соответствие ключам GDD «Assets»: `music_loop` → `music_loop.wav`;
`sfx_combat` → `player_shot` + `enemy_hit` + `player_hit` + `enemy_explosion`;
`sfx_bomb` → `bomb`; `sfx_ui` → `pickup` + `boss_alarm` + `ui_click`.
Музыка зациклена в рантайме: `AudioManager` дублирует поток и ставит
`loop_mode = LOOP_FORWARD`, `loop_begin = 0`, `loop_end = число сэмплов`. Стык лупа
дополнительно сглажен fade 15 мс с обеих сторон (первый и последний сэмпл = 0) — щелчка нет.

## Как перегенерировать

Из корня репозитория:

```powershell
python tools/generate_audio.py
godot --headless --path D:\WW2AirBattles --import
```

Скрипт печатает отчёт: длительность, пик/RMS в dBFS, размер каждого файла и сумму.
Импорт нужен, чтобы Godot обновил `.godot/imported` после перезаписи WAV.

**Важно:** `assets/audio/*.wav.import` фиксируют `compress/mode=0` (импорт как
16-bit PCM без сжатия). Это не косметика: `AudioManager` зацикливает музыку в рантайме
и считает `loop_end` из размера данных (`data.size()/2` для mono 16-bit). При импорте
по умолчанию (QOA) счёт сэмплов идёт по длительности — луп тоже включится, но
плейсхолдеры задуманы как несжатый PCM, чтобы поведение было предсказуемым.
Не меняйте `compress/mode` на 1/2 без повторной проверки лупа.

## Замена на финальные ассеты

Замените WAV файлами **с теми же именами** (mono, 16-bit PCM; музыка 60–90 с, чтобы
осталась петлёй; SFX — короткие). Код менять не нужно: `scripts/audio_manager.gd`
ищет файлы по путям `res://assets/audio/<key>.wav`, а параметры лупа, громкость и
питч-вариации задаёт сам. Если файла нет, AudioManager молча не играет этот ключ
(no-op) — но лучше держать набор полным.

Если финальный трек — стерео или другой битрейт, `AudioManager` всё равно включит
луп: `loop_end` считается из размера данных и формата потока. Для OGG/Vorbis
зацикливание задаётся в импорте (`.import` → Loop), рантайм-настройка WAV к нему
не применяется; используйте WAV для плейсхолдеров.
