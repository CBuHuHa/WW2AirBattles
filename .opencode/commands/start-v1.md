- `GDD.md` — источник истины: 3 миссии, перки, ангар, endless, пиксель-арт, слоты монетизации, раздел «Реализация v1» и критерии приёмки M5–M9.

## Первое действие

1. Прочитай `GDD.md` (разделы «Реализация v1», «Mechanics», «Milestones», «Assets»), `AGENTS.md` и `graphify-out/` при наличии. Для вопросов по коду сначала `graphify query`, потом точечное чтение файлов.
2. Посмотри текущие `scripts/wave_manager.gd`, `scripts/level_controller.gd`, `scripts/enemy_base.gd`, `tests/smoke_test.gd` — только то, что нужно для M5.1.
3. Составь короткий план M5.1 (5–8 пунктов) с файлами, тестами и рисками. Покажи его, затем сразу начинай работу — отдельного подтверждения плана не жди.

- Вынеси волны, состав врагов и босса из кода в `data/missions.json` (или `MissionData`-ресурс, если JSON неудобен): 3 миссии, по 6 волн + босс, состав ровно по GDD.
- `WaveManager` читает миссию по id; хардкод волн удаляется. Поведение миссии 1 («Аэродром») сохраняется 1:1, включая ремкомплект из последнего Ju 87.
- Добавь тест на загрузку данных: 3 миссии, 6 волн, корректные id врагов/боссов, миссия 1 эквивалентна текущей.
- `smoke_test` 518/518 и `juice_integration` 60/60 обязаны остаться зелёными; тесты гоняй по одному, без параллельных adb-операций.
- После M5.1 отчитайся и переходи к M5.2: Bf 110 + боссы Ju 88 и Fw 200 (сцены, скрипты, паттерны по GDD), затем M5.3 — выбор миссии, звёзды и открытие, M5.4 — сейв v2 с миграцией из `[record] best_score`.

## Как делегировать

- `mechanics_developer` — код миссий, врагов, боссов, сейва; давай ему точные файлы, критерии и тесты.
- `sr_game_designer` / `mid_game_designer` — только если в GDD не хватает чисел или паттерна; ответ должен вернуться как предложение с датой для Changelog, а не как «я решил».
- `qa_agent` — тесты, приёмка вехи, прогон на эмуляторе; он же проверяет, что старые проверки не сломаны.
- `ui_ux_agent` — экран выбора миссии, звёзды, HUD перков (M5.3/M6).
- `sr_game_artist` + `technical_artist` — арт M7, параллельно с M6; арт не блокирует M5/M6.
- `game_feel_developer` — только тряска/hit-stop/частицы, не трогай баланс без GDD.
- Сам пиши код только для мелких связок; крупные системы отдавай роли и ревьюй результат.

## Границы и гейты

- Не расширяй скоуп за пределы `Out of scope for v1`; изменения дизайна — только через дату в GDD `Changelog` и с подтверждением владельца.
- Веха закрыта, когда выполнены её критерии приёмки из GDD, тесты зелёные и сборка запускается на эмуляторе.
- Не фальсифицируй арт, тесты и цифры. Если SpriteCook недоступен — стоп и отчёт, а не код-заглушка под видом спрайта.
- Арт-бюджет: ≤ 6 генераций за сессию, ≤ 120 кредитов на M7, стоп ниже 20; перед партией `get_credit_balance`.
- После изменений кода — `graphify update .` и обновление `AGENTS.md`, если поменялись команды, тесты или состояние репозитория.
